Note: DLT Operators (Jio/Fast2SMS) reject templates that:
  1. Do not explicitly contain the Brand Name matching the registered entity string.
  2. Have a placeholder variable ({#var#}) as the very LAST word of the message.

ROOT CAUSE IDENTIFIED:
The "Edit" button on Jio TrueConnect shows a READ-ONLY Template Content field.
This means editing a rejected template does NOT change the actual template text —
only the sample values change. The old rejected text was never replaced.

⚠️  ACTION REQUIRED: You must DELETE both rejected templates and CREATE them
    as brand new templates with the corrected text below.

STEPS:
  1. Go to Content Templates on Jio TrueConnect
  2. Find the rejected template → click DELETE (not Edit)
  3. Click "Add New Template"
  4. Fill in: Header = SEVKAA, Template Name = (same name), Content = (text below)
  5. Submit for approval
